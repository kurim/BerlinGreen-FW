GreenBox Web-Flasher

Custom-Firmware direkt aus dem Browser aufspielen — kein Terminal, keine Installation.

Das Gerät muss einmal geöffnet werden. Die Original-Firmware prüft beim Update ein fest einprogrammiertes, eigenes Zertifikat und akzeptiert ausschließlich Updates vom Hersteller — ein normales WLAN-Update auf diese Firmware gibt es deshalb nicht. Dieser Flasher ersetzt stattdessen das Terminal-Kommando (esptool/flash.sh/flash.cmd) durch eine Weboberfläche; einen USB-UART-Adapter an den Platinen-Pads brauchst du trotzdem. Anleitung zu Gehäuse und Pin-Lage: BerlinGreen_GreenBox_RE.md.

1. Anschließen

  1. USB-UART-Adapter an GND / 3V3 / RXD0 / TXD0 des Moduls anschließen (siehe Anleitung oben).
  2. Falls dein Adapter keinen Auto-Reset (DTR/RTS an EN/IO0) hat: IO0 vor dem Klick unten auf GND legen, danach kurz EN/Reset antippen und IO0 wieder lösen, sobald der Flasher verbindet.
  3. Adapter per USB an den PC anschließen.

2. Flashen

Erkennt automatisch Bootloader, Partitionstabelle und App; der Original-WLAN-Zugang (NVS) bleibt dabei unangetastet und wird von der Custom-Firmware beim ersten Start übernommen.

Dein Browser unterstützt kein Web Serial. Bitte Chrome, Edge oder Opera auf dem Desktop verwenden (Firefox und Safari funktionieren nicht), oder flash.sh / flash.cmd von Hand nutzen. Web Serial ist blockiert (z. B. kein HTTPS-Kontext). Bitte diese Seite über https:// öffnen.

Unterstützt: Chrome, Edge, Opera (Desktop). Nicht unterstützt: Firefox, Safari, mobile Browser — dort stattdessen flash.sh (Linux/macOS) bzw. flash.cmd (Windows) verwenden.

3. Nach dem Flash

  1. Falls IO0 auf GND gebrückt war: Brücke entfernen, sonst startet das Gerät nicht.
  2. Neu starten. Das Gerät übernimmt die WLAN-Zugangsdaten der Original-Firmware automatisch.
  3. Kein WLAN gefunden? Fallback-Access-Point GreenBox-Setup öffnet sich (Standard-Passwort greenbox — im WebUI danach ändern).
  4. WebUI unter http://GreenBox<MAC>.local/ bzw. der IP aus dem Router.

Rückweg

Jederzeit möglich, per UART: esptool write_flash 0 berlingreen.bin mit dem eigenen Dump der Original-Firmware (nicht Teil dieses Repos).
